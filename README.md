# TaskFlow Dashboard Pro

TaskFlow with saved filters, weekly summaries and a compact workload view.
Static front end, no backend required.

## Getting started

```bash
bun install
open index.html
```

The dashboard uses `tiny-format` for number and percentage formatting.

## Features

- Saved filter presets
- Weekly completion summary
- Per-person workload cards
- Keyboard-friendly task list
